# PITWALL — GP de São Paulo

Projeto de estudo de HTML e CSS para a atividade de Linguagem de Marcação (LIMA).

## Como abrir

1. Baixe ou extraia a pasta `pit-wall`.
2. Abra `index.html` no navegador, ou abra a pasta inteira no Visual Studio Code.
3. Para testar a versão mobile, use as ferramentas de desenvolvedor do navegador (F12) e ative a visualização de dispositivo móvel.

## Estrutura

```text
pit-wall/
├── index.html
├── styles.css
├── README.md
└── img/
    └── piloto.jpg
```

## Observações

- A atividade é reproduzida somente com HTML e CSS; os filtros e o formulário são demonstrativos.
- Os dados de classificação e os valores dos ingressos são ilustrativos, conforme o material da atividade.
- A fotografia original enviada pelo aluno foi recortada em formato horizontal e salva como `img/piloto.jpg`, conforme a orientação dos slides (imagem horizontal com o carro em destaque para o fundo do hero).
